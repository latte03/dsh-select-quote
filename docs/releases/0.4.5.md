划词加批注插件 0.4.5：并入官方浮层时按钮文字回来了，而且现在由你决定显不显示文字——只剩图标时，悬停会告诉你每个按钮是什么。

## 几点说明

- **并入官方浮层不再一律图标**：原来判断「贴不贴得下」时量错了盒子——宿主给的容器是 `width: max-content`，它的宽度就等于按钮行自己的宽度，于是永远判定"贴不下"。现在按对话列宽判断，列够宽就出文字，不够才收成图标。
- **新增「显示按钮文字」开关**（设置 → 按钮，最后一行）：关掉后一律图标，悬停与读屏仍保留名称。打开也不保证有文字——列太窄照样自动收起，否则按钮会溢出列外。
- **图标态的悬停提示**：按 Lumno 的动效刻度做——显示延迟 120ms、入场 140ms、从按钮方向移入 3px 并轻微放大、离开立即消失；不做透明度过渡，`prefers-reduced-motion` 下不动。原来那条系统 `title` 已移除，不会出现"两个提示先后弹"。
- **每格一样大**：图标态下动作按钮、分裂箭头、设置齿轮统一 28×28，指针扫过去 hover 底色不再忽大忽小。
- **顺带修好一个配置不生效的问题**：配置更新会逐字段比对，原先手写的比对表漏了新字段，导致这个开关改了界面不跟着变；现在按配置表的键结构化比较，并有逐字段的通知测试兜住。
