# 0.4.6

## 批注卡上的「计数动画」

设置 → 按钮 → 计数动画，三档：**无 / 简约 / 点阵**（默认简约）。

- **简约**：换数时数字从变化的方向滑入，图块补一层淡光——与 0.4.5 相同。
- **点阵**：数字改用 5×7 点阵绘制。一轮回复进行中，数字的亮格自己呼吸（两个
  焦点、相位差半周期），停笔即静止。点径 0.36、格间缝 0.28；笔画加粗一格，
  `1` 的那一竖是两列点。静止时仍是一条 path，只有运行中才改画点。

## 预览卡与悬停面板的入场/退场

点正文角标或 chip 弹出的预览卡，以及批注卡的悬停面板，现在共用同一套动效：

- **整块一起动**：磨砂底板（`::before`）随卡片一起位移，不再出现「底板瞬间
  出现、只有文字在淡入」。
- 入场 300ms，退场 180ms，曲线沿用设置页下拉的 emphasized。
- 由 WAAPI 在元素可见之后显式起播——CSS 关键帧会在节点可见之前就跑，这是
  之前「看不到动画」的真正原因。

## 其它

- 只有一条批注时，卡片标题显示引文、提示行显示评论（无评论则不画）。
- 预览卡宽度改为 160–320 区间，跟内容走。
- `lib/` 不再入库，发布会自动构建。
